# Audio Mixer

Audio Mixer is a small web project that lets you combine different nature sounds to create your own atmosphere. You can mix sounds like rain, birds, wind, a river, and a campfire, adjust their volumes, and choose presets if you don't want to set everything up yourself.


## Features

- **Sound mixing:** Play multiple nature sounds at the same time and adjust their individual volumes.
- **Master volume:** Control the overall volume of all sounds.
- **Mute All:** Mute or unmute every sound with one button.
- **Presets:** Choose between Forest, Cozy Campfire, and Mountain Rain to quickly set up a sound combination.
- **Dynamic background:** The background color changes depending on the volume levels of the sounds.
- **Sleep timer:** Automatically stop all sounds after 15, 30, or 60 minutes.

## Sounds

The mixer includes five sounds:

- Campfire
- Rain
- Birds
- River
- Wind

## Built With

- HTML for the page structure
- CSS for the design and layout
- JavaScript for the audio controls, presets, and timer

No additional libraries or frameworks are required.

## How to Run

1. Download or clone the repository.
2. Make sure the project files are in the correct folders.
3. Check that the audio files are inside the `assets` folder.
4. Open `index.html` in your browser.

You can also open the project in Visual Studio Code and use the Live Server extension to run it locally.

## Notes

The audio files need to be present in the `assets` folder for the sounds to work. Make sure you have permission to use and distribute any audio files included in the project.
